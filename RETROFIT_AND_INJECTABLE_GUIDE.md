## 2. Step-by-Step Implementation in this Project

### Step 1: Dio Module Setup
In [dio_factory.dart](file:///Users/ahmed/Documents/movies/lib/core/network/dio_factory.dart), you register `Dio` inside an abstract `@module` class so `Injectable` / `GetIt` knows how to provide `Dio`:

```dart
// lib/core/network/dio_factory.dart
import 'package:dio/dio.dart';
import 'package:injectable/injectable.dart';
import 'package:pretty_dio_logger/pretty_dio_logger.dart';

@module
abstract class DioModule {
  @singleton
  Dio get dio {
    final dio = Dio(
      BaseOptions(
        baseUrl: 'https://movies-api.accel.li/api/v2/',
        headers: {
          'Accept': 'application/json',
          'Content-Type': 'application/json',
        },
        connectTimeout: const Duration(seconds: 30),
        receiveTimeout: const Duration(seconds: 30),
      ),
    );

    dio.interceptors.add(
      PrettyDioLogger(
        requestHeader: true,
        requestBody: true,
        responseHeader: true,
        maxWidth: 120,
      ),
    );

    return dio;
  }
}
```

### Step 2: Creating the Retrofit API Service
Create your API interface (for example: `lib/features/home/data/api_service/api_service.dart`):

```dart
// lib/core/network/api_service.dart
import 'package:dio/dio.dart';
import 'package:injectable/injectable.dart';
import 'package:retrofit/retrofit.dart';

part 'api_service.g.dart';

@lazySingleton
@RestApi()
abstract class ApiService {
  @factoryMethod
  factory ApiService(Dio dio) = _ApiService;

  @GET('list_movies.json')
  Future<dynamic> getMovies(
    @Query('page') int page,
    @Query('limit') int limit,
  );
}
```

> **Why `@lazySingleton` + `@factoryMethod`?**
> - `@lazySingleton`: Creates a single instance the first time `getIt<ApiService>()` is requested.
> - `@factoryMethod`: Tells `injectable_generator` to invoke `ApiService(getIt<Dio>())` generated by Retrofit (`_ApiService`).

### Step 3: Running Code Generation

### Step 4: Using the Injected Service in Repositories/Cubits

```dart
// lib/features/movies/data/repo/movies_repo.dart
import 'package:injectable/injectable.dart';
import 'package:movies/core/network/api_service.dart';

@lazySingleton
class MoviesRepo {
  final ApiService _apiService;

  MoviesRepo(this._apiService); // Injectable automatically resolves ApiService

  Future<dynamic> fetchMovies(int page) async {
    return await _apiService.getMovies(page, 20);
  }
}
```

```dart
// lib/features/movies/logic/movies_cubit.dart
import 'package:flutter_bloc/flutter_bloc.dart';
import 'package:injectable/injectable.dart';
import '../data/repo/movies_repo.dart';

@injectable
class MoviesCubit extends Cubit<dynamic> {
  final MoviesRepo _moviesRepo;

  MoviesCubit(this._moviesRepo) : super(null);

  void loadMovies() async {
    final result = await _moviesRepo.fetchMovies(1);
    // emit state
  }
}
```

## 3. Injectable: Complete Annotations Reference

| Annotation | Target | Description | Example |
|---|---|---|---|
| `@InjectableInit()` | Top-level function | Marks the dependency injection initialization function (`configureDependencies`). | `@InjectableInit() void configureDependencies() => getIt.init();` |
| `@injectable` | Class | Registers class as a **factory** (a new instance is created every time `getIt<T>()` is called). | `@injectable class LoginCubit extends Cubit { ... }` |
| `@singleton` | Class / Method / Getter | Registers class as an **eager singleton** (instantiated immediately during app startup `getIt.init()`). | `@singleton class AppConfig { ... }` |
| `@lazySingleton` | Class / Method / Getter | Registers class as a **lazy singleton** (created only once, the first time it is accessed). | `@lazySingleton class ApiService { ... }` |
| `@module` | Abstract Class | Used to register third-party classes (e.g. `Dio`, `SharedPreferences`, `FirebaseAuth`) that you cannot annotate directly. | `@module abstract class RegisterModule { @singleton Dio get dio => Dio(); }` |
| `@factoryMethod` | Constructor / Static Method | Tells Injectable which constructor or static creator to use when multiple exist or when using generated classes (like Retrofit). | `@factoryMethod factory ApiService(Dio dio) = _ApiService;` |
| `@preResolve` | Method / Getter inside `@module` | Used when a dependency returns a `Future<T>` (e.g., `SharedPreferences.getInstance()`). Awaits the Future during initialization. | `@preResolve Future<SharedPreferences> get prefs => SharedPreferences.getInstance();` |
| `@Named('name')` | Class / Parameter | Differentiates multiple instances of the same type (e.g. AuthDio vs PublicDio). | `@Named('auth') @singleton Dio get authDio => Dio();` |
| `@Named.from(Type)` | Class / Parameter | Named registration using a Type token instead of a string. | `@Named.from(RepoType) ...` |
| `@InjectParam` / `@factoryParam` | Constructor Parameter | Marks parameters that must be passed at runtime when calling `getIt<T>(param1: ..., param2: ...)`. | `MyCubit(@factoryParam this.id);` |
| `@Environment('env')` | Class / Module method | Registers the dependency only in a specific environment (e.g., `dev`, `prod`, `test`). | `@Environment('dev') class DevApiService implements ApiService {}` |
| `@dev`, `@prod`, `@test` | Class / Module method | Built-in convenience annotations for environments. | `@prod @lazySingleton class ProdRepo implements Repo {}` |
| `@Order(int)` | Class / Module method | Determines the order of registration in generated code (lower numbers initialize first). | `@Order(-1) @singleton class CoreService {}` |
| `@disposeMethod` | Method inside class | Specifies a cleanup/dispose function to execute when a scoped instance or GetIt instance is reset. | `@disposeMethod void dispose() { streamController.close(); }` |

## 4. Retrofit: Complete Annotations Reference

### Class-level Annotations

| Annotation | Description | Example |
|---|---|---|
| `@RestApi(baseUrl: "...")` | Marks an abstract class as a Retrofit client interface. BaseUrl is optional if Dio already has one. | `@RestApi(baseUrl: "https://api.example.com/") abstract class ApiService { ... }` |

---

### HTTP Request Method Annotations

| Annotation | Description | Example |
|---|---|---|
| `@GET('/endpoint')` | Sends an HTTP `GET` request. | `@GET('/movies') Future<List<Movie>> getMovies();` |
| `@POST('/endpoint')` | Sends an HTTP `POST` request. | `@POST('/login') Future<AuthResponse> login(@Body() LoginRequest request);` |
| `@PUT('/endpoint')` | Sends an HTTP `PUT` request. | `@PUT('/users/{id}') Future<User> updateUser(@Path('id') String id, @Body() User user);` |
| `@PATCH('/endpoint')` | Sends an HTTP `PATCH` request. | `@PATCH('/users/{id}') Future<User> patchUser(@Path('id') String id, @Body() Map<String, dynamic> data);` |
| `@DELETE('/endpoint')` | Sends an HTTP `DELETE` request. | `@DELETE('/movies/{id}') Future<void> deleteMovie(@Path('id') int id);` |
| `@HEAD('/endpoint')` | Sends an HTTP `HEAD` request. | `@HEAD('/files/{id}') Future<void> checkFile(@Path('id') String id);` |
| `@OPTIONS('/endpoint')` | Sends an HTTP `OPTIONS` request. | `@OPTIONS('/movies') Future<void> getOptions();` |
| `@CustomMethod('CUSTOM', '/endpoint')` | Sends a custom HTTP verb. | `@CustomMethod('PURGE', '/cache') Future<void> purgeCache();` |

---

### Parameter & Body Annotations

| Annotation | Description | Example |
|---|---|---|
| `@Path('param_name')` | Replaces `{param_name}` in the endpoint URL path. | `@GET('/movie_details.json/{id}') Future<Movie> getMovie(@Path('id') int movieId);` |
| `@Query('key')` | Appends `?key=value` to the URL. If null, the query param is omitted. | `@GET('/movies') Future<List<Movie>> getMovies(@Query('limit') int limit);` |
| `@QueryMap()` | Appends all entries in a `Map<String, dynamic>` as query parameters. | `@GET('/movies') Future<List<Movie>> filterMovies(@QueryMap() Map<String, dynamic> filters);` |
| `@Body()` | Serializes an object or map into JSON for the HTTP request body. | `@POST('/movies') Future<Movie> addMovie(@Body() Movie movie);` |
| `@Field('key')` | Form field parameter (used with `@FormUrlEncoded()`). | `@POST('/token') @FormUrlEncoded() Future<Token> getToken(@Field('grant_type') String grantType);` |
| `@FieldMap()` | Map of form fields (used with `@FormUrlEncoded()`). | `@POST('/token') @FormUrlEncoded() Future<Token> getToken(@FieldMap() Map<String, dynamic> fields);` |
| `@Part(name: 'key')` | Multipart form field / File (used with `@MultiPart()`). | `@POST('/upload') @MultiPart() Future<void> uploadAvatar(@Part(name: 'file') File file);` |
| `@PartMap()` | Map of multipart fields and files (used with `@MultiPart()`). | `@POST('/upload') @MultiPart() Future<void> uploadAll(@PartMap() Map<String, dynamic> map);` |
| `@Header('Header-Name')` | Dynamic HTTP Header passed as a function argument. | `@GET('/profile') Future<Profile> getProfile(@Header('Authorization') String token);` |
| `@Headers({'Key': 'Value'})` | Method-level static headers. | `@Headers({'Accept': 'application/json'}) @GET('/data') Future<Data> getData();` |
| `@Extra({'key': 'value'})` | Passes custom data into Dio's `RequestOptions.extra` (useful for interceptors). | `@Extra({'requireAuth': true}) @GET('/protected') Future<Data> getSecret();` |
| `@CancelRequest()` | Passes a Dio `CancelToken` to cancel an in-flight request. | `@GET('/large-data') Future<Data> getLargeData(@CancelRequest() CancelToken cancelToken);` |
| `@SendProgress()` | Callback to track upload progress (`ProgressCallback`). | `@POST('/upload') Future<void> upload(@Body() FormData data, @SendProgress() ProgressCallback onSend);` |
| `@ReceiveProgress()` | Callback to track download progress (`ProgressCallback`). | `@GET('/download') Future<List<int>> download(@ReceiveProgress() ProgressCallback onReceive);` |
| `@DioResponseType(ResponseType.bytes)` | Overrides the Dio response type (e.g., `ResponseType.bytes`, `ResponseType.stream`, `ResponseType.plain`). | `@DioResponseType(ResponseType.bytes) @GET('/download') Future<List<int>> downloadFile();` |

## 5. Complete Working Example

### Defining Model with `json_serializable`
```dart
// lib/features/movies/data/models/movie_response.dart
import 'package:json_annotation/json_annotation.dart';

part 'movie_response.g.dart';

@JsonSerializable()
class MovieResponse {
  final String status;
  final MovieData data;

  MovieResponse({required this.status, required this.data});

  factory MovieResponse.fromJson(Map<String, dynamic> json) =>
      _$MovieResponseFromJson(json);

  Map<String, dynamic> toJson() => _$MovieResponseToJson(this);
}

@JsonSerializable()
class MovieData {
  @JsonKey(name: 'movie_count')
  final int movieCount;
  final int limit;
  final int page_number;

  MovieData({
    required this.movieCount,
    required this.limit,
    required this.page_number,
  });

  factory MovieData.fromJson(Map<String, dynamic> json) =>
      _$MovieDataFromJson(json);

  Map<String, dynamic> toJson() => _$MovieDataToJson(this);
}
```

### Defining the Retrofit API Service
```dart
// lib/core/network/api_service.dart
import 'package:dio/dio.dart';
import 'package:injectable/injectable.dart';
import 'package:retrofit/retrofit.dart';
import 'package:movies/features/movies/data/models/movie_response.dart';

part 'api_service.g.dart';

@lazySingleton
@RestApi()
abstract class ApiService {
  @factoryMethod
  factory ApiService(Dio dio) = _ApiService;

  @GET('list_movies.json')
  Future<MovieResponse> getMovies({
    @Query('page') int? page,
    @Query('limit') int? limit,
    @Query('quality') String? quality,
    @Query('minimum_rating') int? minimumRating,
    @Query('query_term') String? queryTerm,
    @Query('genre') String? genre,
    @Query('sort_by') String? sortBy,
    @Query('order_by') String? orderBy,
  });

  @GET('movie_details.json')
  Future<dynamic> getMovieDetails({
    @Query('movie_id') required int movieId,
    @Query('with_images') bool withImages = true,
    @Query('with_cast') bool withCast = true,
  });

  @GET('movie_suggestions.json')
  Future<dynamic> getMovieSuggestions({
    @Query('movie_id') required int movieId,
  });
}
```
